# Projeto Comprar

![Demonstração do app](./src/assets/documentation/videoApp.gif)

App de lista de compras para facilitar o usuário na hora de ir ao supermercado.
Desenvolvido para praticar React Native com TypeScript utilizando o Expo.

![React Native](https://img.shields.io/badge/React_Native-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![Expo](https://img.shields.io/badge/Expo-1C1E24?style=for-the-badge&logo=expo&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)

## Funcionalidades

- [x] Funcionalidade 1: Adicionar Itens
- [x] Funcionalidade 2: Listar Itens
- [x] Funcionalidade 3: Status do item (pendente ou comprado)
- [x] Funcionalidade 4: Apagar item
- [x] Funcionalidade 5: Apagar a lista toda

---

## Tecnologias e decisões técnicas

- **React Native + Expo** — Por ser um aplicativo mobile e que funcione em diversos dispositivos, entendi ser o mais óbvio utilizar o React Native com o Expo.

---

## Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/pach33co/projeto-app-comprar.git

# Entre na pasta
cd comprar

# Instale as dependências
npm install

# Rode o projeto
npx expo start
```

## Estrutura de pastas

```
src/
├── app/            # Rotas (Expo Router)
├── assets/         # Imagens utilizadas no projeto
├── components/     # Componentes reutilizáveis
├── storage/        # Armazenamento das informações
└── types/          # Status do Item
```
